# 阶段与验收参考

按当前任务使用，不要求用户先做完所有阶段才能得到一个具体答案。可以并行准备不相互依赖的草稿；开放接单前必须解决其关键经营与交易依赖。

| 阶段 | 最小成果 | 验收证据 | 常见误判 |
| --- | --- | --- | --- |
| 明确方向 | 顾客 问题 范围 预算与责任人 | 能解释为何选择并列出暂不做事项 | 先买域名和插件再想业务 |
| 研究需求 | 搜索意图与竞品对照 | 来源 日期 国家与限制 | 把估算流量或搜索量当销量 |
| 核实商品 | 型号事实表和缺口 | 对应型号资料及必要测试 | 拼接不同版本 继承未经证实的性能 |
| 成本和履约 | 可比报价与逐单成本 | 包含项 责任 有效期 退换安排 | 产品价等于落地成本 零库存等于零风险 |
| 品牌基础 | 品牌及账户资产清单 | 实际访问 HTTPS 邮件往返和归属 | 登录成功等于拥有全部权限 |
| 页面结构 | 每页顾客任务与下一步 | 能走通理解 比较 选择 交易路线 | 首页 商品和指南重复同一段文案 |
| AI 内容素材 | 版本化的文案和图片 | 型号对照 审稿记录 合适披露 | 场景图等于测试 生成图等于供货版本 |
| 商店落地 | 原生商品 变体 页面与购物车 | 选项 数量 金额 链接 手机检查 | 预览动画等于真实交易 |
| 交易政策 | 承诺与后台规则对照 | 商品页 政策 结账 实际履约一致 | 保存文案即完成政策落地 |
| 搜索内容 | 问题与页面地图 | 有用内容 可抓取链接 真实元数据 | 发布等于索引 索引等于流量 |
| 数据验收 | 功能和事件分列的记录 | 实际动作 参数 同意状态 订单对照 | 连接成功等于完整归因 |
| 发布与复核 | 发布决定 回退及人工履约流程 | 接单前提满足 公开访问检查 | 换主题等于开售 广告就绪等于店铺就绪 |

## 应分别判断的三个结果

1. 建站成果可评审：内容和设计足以供审查，不代表可接单。
2. 可以公开接单：商品供货、履约、政策、交易、客服和适用要求已满足，负责人已批准。
3. 可以启用某个渠道：该渠道的资格、素材、预算、商品源和数据要求已满足，并另获批准。

未启用广告可以后置广告专属设置；不能因此后置真实商品、支付或履约前提。

## 上线验收的合理证据

- 商品和图片对应实际可交付版本；关键规格、限制与供货能力有依据。
- 价格、变体、库存来源、配送范围和税费处理已确认；不得凭空填库存。
- 公开政策、后台规则和结账显示一致；专业判断由合适的人完成。
- 客服渠道和通知链路可用。认证状态不代替真实收件测试。
- 从未登录消费者视角检查页面和手机交互；密码保护期间明确测试范围。
- 受控测试支付和必要的退款流程有明确批准，了解费用与测试模式影响。
- 关键事件与订单核对；收数延迟、权限或隐私限制写明，不伪造补齐。
- 手动发货、第三方发货服务和订单自动化均按实际采用情况检查。
- 发布范围、时点、负责人和回退方式明确。
