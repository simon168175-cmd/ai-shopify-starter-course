## 核心方法

问题 → 证据 → 决定 → 实施 → 验收 → 留档。

始终区分“已配置”“已验证”和“待验证”。预览可点击不等于真实交易可用；账号已连接不等于数据闭环；主题发布也不等于公开开售。

## Skill 的范围

`independent-store-launch` 是纯指导型技能，帮助 AI 判断阶段、整理证据、提出下一步和验收标准。入口与参考文件须一起保留，加载方式见使用说明和工具当前官方文档。

它不会自动连接店铺，不含凭据，也不附自动投放、付款、退款、发货或消息脚本。需要操作账户时，应另行核对工具权限和用户授权。

## 案例与隐私边界

- 真实品牌、域名、账号、联系方式和供应商信息均已匿名化；不提供原站截图或经营后台资料。
- 这是一份建站与上线准备教程，不是已经验证盈利的商业案例。
- 案例中的真实付款、完整订单通知、购买事件与履约等尚未全部验收，正文保留这些限制。
- 示例数字不代表当前平台费率，也不能直接用作物流、退货、税务或商品安全承诺。
- 平台界面和政策会变化，实际操作时应重新核对官方资料及自己的账户。
